# collider-visionos

Hosted Flutter web build of Collider Vision OS (unified shell).

- Live site: https://pharcydeancient.github.io/collider-visionos/
- The site is served by GitHub Pages from the `gh-pages` branch.
- `main` holds only the deploy workflow (`.github/workflows/deploy.yml`), which downloads a build tarball, checks its sha256, and commits it to `gh-pages`.
